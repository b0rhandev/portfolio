## 🛠️ Tech Stack & Tools
This project was built using the following technologies:
* **Front-End:** HTML5, Vanilla JavaScript
* **Styling:** Tailwind CSS (for rapid, responsive UI design)
* **Automation & AI:** Integrated a custom AI assistant widget connected via **n8n** webhooks and AI agents.

I am a passionate Front-End Developer with a strong background in instrumentation engineering. I specialize in building creative web experiences and connecting modern websites to smart business automation tools (like n8n) to create functional, AI-powered applications. 

* **Focus Areas:** React, Next.js, Tailwind CSS, n8n Automation, AI Workflows.
* **Available for:** Freelance projects and full-time roles in Front-End development.
